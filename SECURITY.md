# Security Policy 🛡️

## Supported Projects
All active production repositories maintained under [@yogender-ai](https://github.com/yogender-ai) receive continuous vulnerability monitoring.

## Reporting a Vulnerability
If you discover a security vulnerability or potential exposure in any project, please do not open a public issue.

Instead, please send an encrypted or direct disclosure report to:
- **Email**: `yogender.aiml@gmail.com`
- **Subject**: `[SECURITY VULNERABILITY] <Project Name>`

Reports are typically reviewed and addressed within 24–48 hours. Thank you for helping keep open-source software secure!
